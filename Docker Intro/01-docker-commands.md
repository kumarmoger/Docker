==================
Docker Commands
==================

1. docker images

Purpose: Displays all Docker images available on your system.

docker images
Example Output
REPOSITORY          TAG       IMAGE ID       CREATED        SIZE
nginx               latest    abc123xyz      2 weeks ago    188MB
mysql               8.0       def456uvw      3 weeks ago    600MB

Explanation
Repository → Image name.
Tag → Version of the image.
Image ID → Unique identifier.
Created → When image was built.
Size → Storage occupied.

Use this command to verify whether an image exists locally before running a container.
-----------

2. docker pull <image-name>

Purpose: Downloads an image from Docker Hub or another registry.

docker pull nginx
What Happens?
Docker connects to Docker Hub.
Downloads image layers.
Stores them locally.
Example
docker pull mysql:8.0

Downloads MySQL version 8.0.

Use Case

Before running a container, you must have the image available locally.
--------------------------

3. docker run <image-name>

Purpose: Creates and starts a container from an image.

docker run nginx
What Happens?
Docker checks if image exists locally.
If not, downloads it.
Creates a container.
Starts the container.
Example
docker run -d nginx
-d = Detached mode (runs in background)
Relationship
Image → Blueprint
Container → Running instance of image

One image can create multiple containers.
----------------------------------------------

4. docker ps

Purpose: Shows currently running containers.

docker ps
Example Output
CONTAINER ID   IMAGE   STATUS
a1b2c3d4       nginx   Up 5 minutes
Use Case

Check which containers are active.
----------------------------------------------

5. docker ps -a

Purpose: Shows all containers.

docker ps -a

Includes:

Running containers
Stopped containers
Exited containers
Example
CONTAINER ID   STATUS
123abc         Up 10 minutes
456def         Exited (0)

Useful when troubleshooting failed containers.
-----------------------------------------

6. docker ps -q

Purpose: Displays only container IDs.

docker ps -q
Example Output
a1b2c3d4
e5f6g7h8
Use Case

Often combined with other commands.

Example:

docker stop $(docker ps -q)

Stops all running containers.
--------------------------------------------------------

7. docker logs <container-id>

Purpose: Displays logs generated by a container.

docker logs a1b2c3d4
Example Output
Tomcat started on port 8080
Application deployed successfully
Use Case

Troubleshooting application startup issues.

Follow Logs Continuously
docker logs -f a1b2c3d4

Similar to:

tail -f logfile.log

-------------------------------------------
8. docker stop <container-id>

Purpose: Gracefully stops a running container.

docker stop a1b2c3d4
What Happens?
Docker sends SIGTERM.
Application gets time to shut down.
Container stops.
Example
docker stop nginx-container

Use before removing a container.
------------------------------------------------

9. docker start <container-id>

Purpose: Starts a stopped container.

docker start a1b2c3d4
What Happens?

Container starts with previously saved configuration.

Difference
docker run nginx

Creates a new container.

docker start container-id

Starts an existing container.
------------------------------------------

10. docker stop $(docker ps -q)

Purpose: Stops all running containers.

docker stop $(docker ps -q)
Breakdown
docker ps -q

Returns:

123abc
456def
789ghi

Then Docker executes:

docker stop 123abc 456def 789ghi
Use Case

Useful before system cleanup.
----------------------------------------------------------------

11. docker rm <container-id>

Purpose: Deletes a stopped container.

docker rm a1b2c3d4
Important

Container must be stopped first.

Wrong:

docker rm running-container

Correct:

docker stop running-container
docker rm running-container
Force Remove
docker rm -f container-id

Stops and removes in one command.
--------------------------------------------------------------------------

12. docker rmi <image-name>

Purpose: Deletes a Docker image.

docker rmi nginx
Important

No container should be using the image.

Example
docker rmi mysql:8.0

Removes MySQL image.

Force Remove
docker rmi -f nginx
----------------------------------------------

13. docker system prune -a

Purpose: Cleans up unused Docker resources.

docker system prune -a
Removes

✅ Stopped containers

✅ Unused networks

✅ Dangling images

✅ Unused images

✅ Build cache

Example

Before cleanup:

Images: 20
Containers: 15

After cleanup:

Images: 3
Containers: 2
Warning

This command can delete large amounts of data.

Docker asks for confirmation:

WARNING! This will remove:
- all stopped containers
- all unused images
- build cache
Continue? [y/N]
